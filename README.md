## 🧠 Evaluation principles

<details>
<summary><strong>What makes a benchmark task trustworthy?</strong></summary>

<br />

1. **The goal is concrete.** An agent can tell what success should look like.
2. **The environment is controlled.** Setup and dependencies do not change the answer unexpectedly.
3. **The verifier owns the truth.** The evaluator checks the resulting state rather than trusting a self-reported answer.
4. **Shortcuts are not success.** No-op, partial, and hard-coded solutions are handled deliberately.
5. **The evidence is explainable.** A reviewer can understand why the task passed or failed.

</details>
